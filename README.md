## ✨ _介绍_

面向 QQ 群的自动化群管插件：**全体禁言**（即时与定时）、**群消息违规审核**（LLM + 关键词，自动撤回/禁言）、**高召回模式**（定时启用另一套更严审核规则与独立模型）、**入群审批**（QQ 等级限制、退群后再次申请限制、自动审核、自动改群名片、进群欢迎），并自带 WebUI 管理面板，按群独立配置。

## 🧩 _功能一览_

- **全体禁言**：一键开启/解除，支持单次、每日重复与按周几的定时禁言，重启后任务保留
- **群消息审核**：LLM 判定 + 关键词命中，违规自动撤回、禁言，支持图片消息
- **消息合并审核**：同一成员连发消息自动攒成一批（每条新消息都会重置倒计时），静默满设定秒数后整批送 LLM 判定，违规时该区间内的消息全部撤回
- **高召回模式**：可设定每日时段自动启用另一套更严格的审核规则与单独选择的模型，开启/关闭可在群内发送提示，也支持手动随时切换
- **违规记录**：按成员累计违规次数，随时查看与清零，重启不清零
- **入群审批**：按群自定义审核要求与 QQ 等级限制，退群后设定时间内再次申请自动拒绝，自动同意/拒绝，通过后自动改群名片并发欢迎
- **群名片锁定**：把指定成员的群名片固定为指定值，被改动后自动改回，支持定时轮询兜底
- **自定义通知**：各类处置与审批结果都可在群里发送提示，可 @ 相关成员
- **WebUI 管理面板**：选群后可视化配置与查看，保存即生效，支持跨群同步配置
- **权限控制**：敏感操作校验操作者权限，可选是否允许群主/群管理员使用，也可设置不受审核的白名单成员

## 🖥️ _WebUI 管理面板_

在 AstrBot 后台的插件详情页打开「guard」页面，**打开后先选择群**（列出机器人已加入的全部群，并标注群内身份：群主 / 管理员 / 非管理员），之后所有操作都针对该群；机器人在群内非群主/管理员时，需要管理员权限的设置会自动停用且不可修改（「AI 仅回复管理」与「进群欢迎」不依赖群管理权限，仍可配置）：

- **配置**：从 AstrBot 已配置的 LLM 中为该群选择审核模型（无需在插件里填写接口与 Key），并可视化配置该群的全部策略（审核开关与处置方式、阶梯禁言、关键词、入群审批、通知消息、权限等），保存即生效；支持**从其他群一键同步**全部配置到当前群
- **高召回**：配置每日定时启用时段、高召回专属审核要求与独立模型，查看当前生效状态，并支持手动「立即开启 / 立即关闭」
- **违规记录**：查看当前群各成员累计违规次数，支持单个清零与全部清零
- **定时禁言**：查看当前群的定时任务（模式/时间/状态），可视化设置（单次/每日/每周）与删除
- **入群审批**：配置当前群的审核模型、审核要求、QQ 等级限制与退群后再次申请拦截、自动拒绝与拒绝说明，以及进群欢迎与改名提示；可查看与清理各群退群记录
- **群名片锁定**：添加/解除锁定规则，表格实时显示每个成员名片的「正常 / 已偏离」状态，支持单条或整群立即恢复

## 🔇 _全体禁言_

### 群内指令

| 指令                     | 说明                                        |
| ---------------------- | ----------------------------------------- |
| `/全体禁言`                | 立即开启本群全体禁言                                |
| `/解除全体禁言`              | 立即解除本群全体禁言                                |
| `/定时禁言 10:00 20:00`    | 单次定时禁言：10:00 自动开启，20:00 自动解除              |
| `/定时禁言 now 90`         | 立即开启，90 分钟后自动解除                           |
| `/定时禁言 每日 22:00 06:00` | **每日重复**：每天 22:00 开启、次日 06:00 解除，自动循环直到取消 |
| `/定时禁言 周一 22:00 06:00` | **按周几设置**：为周一设置独立时段（支持 周一-周五、周末、工作日 等）    |
| `/定时禁言 删除 周一`          | 删除指定星期的规则                                 |
| `/定时禁言`                | 查询本群定时任务（含每日/每周规则）                        |
| `/定时禁言 取消`             | 取消本群全部定时任务（若禁言已开启会自动解除）                   |

### 时间规则

- 开始时间写成 `HH:MM`，若该时刻已过则自动顺延到明天；也可以用 `now` 表示立即开启
- 结束时间写成 `HH:MM`，若早于或等于开始时间则视为次日凌晨（如 `22:00 06:00` 即次日 6 点解除）；也可以写分钟数表示持续多久
- **每日模式**：每天循环执行，跨天自动处理，直到取消；机器人重启后自动恢复
- **每周模式**：可为每周不同星期设置不同时段，重复设置按星期合并/覆盖，支持 `周一-周五`、`周末`、`工作日` 等快捷写法
- 单次任务的开始时间距当前与持续时长最多不超过 7 天
- 设置新的定时任务时，若与已有任务时间窗口重叠，会提示冲突任务并要求先删除其中一个，不会静默覆盖

### LLM 工具

开启后 AI 助手也能通过对话完成这些操作：

- **即时全体禁言**：按指令开启或解除本群全体禁言
- **定时全体禁言**：设置立即开启、指定时间开始、每日重复或按周几的定时禁言，并可附带设置原因
- **查询定时任务**：查询本群当前全部定时禁言任务（模式/时间/状态），设置前先查询可避免时间冲突

## 🛡️ _违规消息审核_

### 审核方式

插件提供两套**互相独立**的审核机制，可单独开启、也可同时使用：

- **LLM 审核**：使用 AstrBot 已配置的 LLM 判定消息是否违规——先在 AstrBot WebUI 中添加好模型，再到插件 WebUI 为每个群选择**主模型**、**备用模型**与**识图审核模型**。主模型出现技术性失败（请求错误、空输出、解析失败）时自动切换备用模型；模型因内容高风险拒绝输出时，按违规直接处置（可关闭改为保守跳过）
- **关键词检测**：无需配置模型、不消耗 LLM 调用，命中即处置。分**轻度**与**重度**两级，两级各自拥有处置方式、阶梯禁言与撤回阈值，计数互相独立；同一条消息同时命中轻/重时按**重度**处置
- **命中即不回复**：轻/重两级关键词命中时都会在 AI 会话发起前拦截，机器人不会回复该消息；随后的撤回/禁言/计数由后台审核任务执行，只执行一次，不会重复处置

### 图片与审核范围

- 图片消息同样可审核：审核模型支持识图时直接带图判定，不支持时由**识图审核模型**带图出判定；纯图片消息也会审核，违规记录中标注图片数量
- 审核对象为群内普通成员消息；AstrBot 管理员、群主/群管理员与白名单成员不受审核
- 可设置同一成员的审核间隔，避免刷屏造成大量调用；设为 0 则每条消息都审核

### 消息合并审核

针对"把一句话拆成好几条发"的刷屏式违规（例如先发广告、再补联系方式、再补二维码），单条审核容易只看半句话就放过。开启**消息合并审核**后改为攒批判定：

```
A 到达 → 开始 10 秒倒计时
B 到达（窗口内）→ 倒计时重置为 10 秒
C 到达（窗口内）→ 倒计时继续重置 …… D、E、F 同理
倒计时走完仍无新消息 → 把 A B C D E F 作为一批交给 LLM 判定
判定违规 → 这 6 条消息全部撤回（并按配置禁言、计数）
```

- **合并窗口（秒）**：即上图的 10 秒，按群配置（默认 10，最长 600）；**每条新消息都会把倒计时重置为完整窗口**，直到该成员安静满一个窗口才送审
- **整批处置**：批次内任意一条被判定违规，该区间内该成员的全部消息一并撤回、按一次违规计入阶梯禁言，违规记录里保留这批消息的完整原文
- **按成员分别攒批**：不同成员、不同群的倒计时互不影响，不会互相"续命"；只有一条消息时同样在窗口结束后审核
- **图片一起送审**：整批消息中的图片一起交给识图模型（单次最多 3 张，超出时**丢最旧的、保最新的**，并在送审文本中说明还有图片未附上）；纯图片消息在送审文本中标注为 `[图片消息]`。仅能送审 OneBot 给出的 http/https 图片地址（`file://`、base64 形式的图片无法送审）
- **关键词仍然即时处置**：命中轻/重违规词时同样按整批撤回，且在 AI 会话发起前拦截，机器人不会回复
- **与审核间隔的关系**：开启合并审核后，攒批本身已经大幅降低调用频率，「审核间隔」不再生效（避免窗口内消息被静默丢弃）；未开启合并审核时按原逻辑逐条审核
- 该功能默认关闭，不影响原有逐条审核行为

### 处置与阶梯

- **处置方式**：仅禁言 / 仅撤回 / 撤回并禁言
- **阶梯禁言**：同一成员违规次数越多，禁言时长越长（按倍数递增并有封顶）；关闭后固定为基准时长
- **撤回后自动禁言**：仅撤回模式下，撤回达到设定次数后自动升级为禁言
- **审核要求自定义**：可写明本群禁止的内容（广告/辱骂/引战/涉黄赌毒等），审核将侧重这些要求

违规次数按群分别统计并持久化保存，机器人重启不丢失；违规记录页按 LLM / 轻度词 / 重度词三种来源分别展示与清零。

## 🚨 _高召回模式_

面向深夜、活动等需要更严审核的时段：到点自动切换到另一套审核规则与单独选择的模型，结束后恢复常规审核。在 WebUI「高召回」页按群配置：

- **每日定时开启**：设置开启与关闭时间（如 `22:00` 开启、次日 `06:00` 关闭），每天自动循环；结束时间早于开始时间视为次日凌晨。机器人重启后状态自动恢复，处于时段内不会重复打扰
- **另一个审核规则**：生效期间使用独立的高召回审核要求（提示词），可写明更严策略（如存在任何疑似违规一律判定）；留空则沿用配置页的常规审核要求
- **审核模型单独选择**：高召回可使用与常规审核**不同**的主 / 备用 / 识图模型（三项留空时沿用常规模型），例如平时用快速模型、高召回时段换用更强模型
- **开启 / 关闭提示**：切换时可在群内发送提示，支持 `{start_time}` `{end_time}`（定时的开始 / 结束时间），留空不发送；发送失败会在连接恢复后自动补发
- **手动切换**：可随时「立即开启 / 立即关闭」；手动状态到下一个定时节点自动交还定时规则（未启用定时则长期保持），便于临时启用
- 关闭「每日定时开启高召回」开关时，若高召回正在生效会自动关闭并发送提示，避免残留生效无人关闭
- 高召回是群消息 LLM 审核的增强：仅在「群消息违规审核」开启时生效，处置方式、阶梯禁言、违规计数与常规审核共用

## 🚪 _入群审批_

在 WebUI「入群审批」页按群配置，开启后生效：

- **审核模型独立选择**：入群审批可以使用与群消息审核**不同**的模型（主/备用/识图），三项都留空时自动沿用消息审核所用的模型
- **审核要求完全自定义**：留空时使用内置默认要求（申请信息需同时包含昵称与 OID/UID 纯数字编号，缺任一即不通过）；自行填写后完全按你的要求判定，例如"必须包含真实姓名与学号，且备注中不得含广告或二维码"
- **QQ 等级限制**：可要求申请人达到设定的最低 QQ 等级（星星=1、月亮=4、太阳=16、皇冠=64），等级不足直接按「等级不足」处理、不再送 LLM 审核；无法获取等级时可选择继续正常审核 / 按等级不足拒绝 / 跳过自动审批留给管理员；等级不足的拒绝理由可自定义（支持 `{level}` `{min_level}`）
- **退群后再申请限制**：开启后按群记录成员退群时间（可选「仅主动退群」或「主动退群 + 被移出」），退群后设定时长内再次申请直接按「退群时间不足」处理、不再送 LLM 审核；拒绝理由可自定义（支持 `{window}` `{elapsed}` `{remain}` `{left_time}`）；「入群审批」页可直接查看与清理各群退群记录
- **不满足要求自动拒绝**：开启后审核不通过会自动拒绝申请；关闭则只跳过自动审批（不拒绝也不同意），留给管理员手动处理
- **拒绝说明可自定义**：可分别设置发给申请人的拒绝理由回执，以及在群内发布的拒绝提示（可 @ 申请人）
- **通过后自动处理**：同意入群并记录 OID，对方进群后自动把群名片改为『QQ昵称_OID』，并按设置分别发送改名成功/失败提示
- **进群欢迎**：成员进群时可发送欢迎消息并 @ 新成员，留空则不发送

模型不可用、调用失败或输出无法解析时**不会**自动拒绝（避免误拒），该申请保留给管理员手动处理。

## 🔒 _群名片锁定_

在 WebUI「群名片锁定」页按群配置，开启后生效。用于把管理员、防刷屏等关键成员的群名片固定下来，任何人改动后都会自动改回。

- **按成员锁定**：以「QQ 号 + 锁定名片」成对添加规则，可加备注便于管理；同一 QQ 号重复添加会覆盖旧规则
- **事件即时恢复**：成员群名片一旦被改动（本人改、管理员改），机器人立即改回锁定值
- **定时轮询兜底**：部分平台不推送名片变更事件、后台批量改名等场景事件会丢失；开启轮询后按设定间隔（最小 60 秒）主动比对并恢复
- **状态可视**：规则表格实时显示每个成员的当前名片与「正常 / 已偏离」状态，支持单条「立即恢复」或「立即执行全部锁定」
- **便捷填表**：可从群成员中读取名片直接回填 QQ 号与当前名片，省去手动查询
- **恢复提示语**：改回后可向群里发一条提示（可 @ 该成员），避免成员不知情反复改动

### 实现说明

- 名片变更通过 **aiocqhttp 原生 `group_card` 通知**捕获：AstrBot 消息管线会把 notice 事件转成空消息并在唤醒检查阶段丢弃，`@filter` 处理器收不到该事件，因此直接在平台客户端挂原生回调
- **回声抑制**：机器人自己写名片同样会触发一条通知，插件会登记"刚写过的成员"，短时间内忽略同源事件，避免在两个名片之间反复横跳
- **权限要求**：改他人名片需要群主/管理员权限。机器人非管理员的群会跳过锁定（前端按钮同步置灰），仅提示一次不刷日志

## 📌 _自定义通知_

- **全体禁言通知**：开启/解除全体禁言时发送的消息，可带上本次禁言的开始与结束时间，留空不发送
- **违规通知**：处置违规成员后在群内发送提示，可 @ 该成员（显示其群昵称）、带上群昵称、违规次数与禁言时长，留空不发送
- **入群相关通知**：拒绝回执、拒绝提示、进群欢迎、改名成功/失败提示均可自定义文案，可 @ 相关成员或带上昵称/OID，留空不发送
- **名片锁定通知**：成员名片被改回锁定值时在群内提示，支持 `{at_user}` `{nickname}` `{user_id}` `{card}` `{old_card}`，留空不发送

## 📜 _权限控制_

- **权限验证**（默认开启）：全体禁言、定时禁言等敏感操作校验操作者权限
- **允许群主/群管理员使用**（默认关闭）：开启后群主与群管理员也可使用本插件功能
- **非管理群自动停用**：机器人在群内非群主/管理员时，该群需要管理员权限的功能（违规审核与处置、定时禁言、高召回、入群审批与自动改名）一律停用（不执行、不发送），WebUI 中相关设置与按钮同步禁用；**「AI 仅回复管理」与「进群欢迎」不依赖群管理权限，仍可正常配置与生效**；违规记录与本地数据仍可查看清理；机器人重新获得权限后其余功能自动恢复

将本目录打包为 zip，在 AstrBot 插件管理页安装；或直接放入 `plugins` 目录后重启。
